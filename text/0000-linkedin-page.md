# Summary
[summary]: #summary

This RFC proposes creating an official LinkedIn Page for Cloud Native Buildpacks to provide a central place for project announcements, releases, community news, and conference content.

# Definitions
[definitions]: #definitions

N/A

# Motivation
[motivation]: #motivation

Cloud Native Buildpacks does not currently have an official LinkedIn presence. Project news is shared through personal profiles, leaving people without a central Page to follow or tag. With the Buildpacks Summit in March 2027, an official Page would provide a consistent place to share announcements, speaker highlights, releases, and other project news.

# What it is
[what-it-is]: #what-it-is

The project will create and maintain a vendor-neutral LinkedIn Page with the following details:

- Name: Cloud Native Buildpacks
- URL: <https://www.linkedin.com/company/buildpacks>, or the closest available URL
- Website: <https://buildpacks.io>

The Page will share project releases, Summit and conference talks, blog posts, and community news.

# How it Works
[how-it-works]: #how-it-works

The Page will have at least two super admins at all times, along with content admins responsible for publishing updates. The initial super admins and content admins will be confirmed before the Page is created.

Admin changes will be requested in the `#buildpacks-learning-team` Slack channel and approved by the Steering Committee, which oversees project branding under [RFC 0137](https://github.com/buildpacks/rfcs/blob/main/text/0137-steering-committee.md). An approved change will be made by a super admin.

Access will be removed when an admin steps down or becomes inactive. If a super admin steps down, becomes inactive, or loses access to their account, a replacement will be appointed promptly so that the Page does not depend on a single person.

Setup guidance:

- Creating the Page: [LinkedIn Help](https://www.linkedin.com/help/linkedin/answer/a543852), [video](https://youtu.be/i2DgjpwEsHk)
- Admin roles: [LinkedIn Help](https://www.linkedin.com/help/linkedin/answer/a541981), [video](https://youtu.be/BhpXMNyePv4)

# Drawbacks
[drawbacks]: #drawbacks

- The Page will require ongoing effort to publish relevant updates and maintain its administrator list.
- The project will depend on LinkedIn for access to this communication channel.

# Alternatives
[alternatives]: #alternatives

- Continue sharing project updates through personal profiles only, without an official Page.
- Use other project communication channels without establishing a LinkedIn presence.

# Prior Art
[prior-art]: #prior-art

- [Dapr](https://www.linkedin.com/company/daprdev)
- [Knative](https://www.linkedin.com/company/knative)
- [Kubernetes](https://www.linkedin.com/company/kubernetes)
